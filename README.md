# Docker Foundations

Companion code for the **Docker Foundations** series on [TechDevMantra](https://www.techdevmantra.com/guides). Each folder holds the exact, reproducible files from one post, tested on real Docker (Engine 29.8.0, Ubuntu 24.04).

| Folder | Post |
|---|---|
| [`03-compose-stack/`](03-compose-stack) | [Docker Compose: Run a Multi-Service Stack (Web + Postgres + Redis)](https://www.techdevmantra.com/guides/docker-compose-multi-service-stack) |
| [`04-dockerfiles/`](04-dockerfiles) | [Lean Docker Images: Multi-Stage Builds and Layer Caching](https://www.techdevmantra.com/guides/lean-docker-images-multi-stage-builds) |
| [`06-volumes-networks/`](06-volumes-networks) | [Where Your Data Lives: Docker Volumes, Bind Mounts, and Networks](https://www.techdevmantra.com/guides/docker-volumes-bind-mounts-networks) |

The first two posts in the series, [Install Docker](https://www.techdevmantra.com/guides/install-docker-macos-windows-wsl2-linux) and [Run Your First Containers](https://www.techdevmantra.com/guides/run-your-first-docker-containers), are command-only and ship no code.

## Prerequisites

Docker Engine or Docker Desktop. If you need to install it, start with the install guide linked above.

## Usage

Each folder is self-contained. Open its README, or read the matching post, and run the commands there.
